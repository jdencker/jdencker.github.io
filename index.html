Node Hub

Flagship

Central hub for a fleet of Raspberry Pi sensor nodes. A FastAPI backend polls each node on a schedule, owns all naming and sensor-role mapping, and records time-series measurements in Postgres; a React dashboard handles live monitoring and hardware control — LED flash, device recovery, node reboot. Ships as a Docker Compose stack behind an nginx same-origin /api proxy — no CORS layer at all, by construction.

Approach

Whether I'm shipping a Raspberry Pi sensor network for an industrial process or the data pipelines an Army command runs on, I build the same way: understand the typically messy current state, ship something that works, then rebuild it until it's right. Across roles as an infantry officer, AI product lead, and data architect, the work has been consistent: bring structure to ambiguous problems, decide what matters first, and build coherent systems teams can rely on. The hardest part is rarely the technology. It's leading the organizational change required to adopt it — often without formal authority — by making the case, communicating the value, and delivering results people can see.
