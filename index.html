Selected Work

01

Node Hub

Flagship
Customer Swinergy, Inc. ↗
Seed-round startup | 3 employees

This system consists of three main segments — which together, automate data collection and provide real-time insights into a patented 3-stage methane production process. Each stage's sensors connect to a node server, which makes readings accessible via API. A central hub captures real-time readings and alerts, visualizes the current state, and stores data both locally and in the cloud. Finally a VPN service enables secure remote access, without exposing the system to the public internet.
