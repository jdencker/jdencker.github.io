# Font assets

The portfolio self-hosts Latin WOFF2 subsets of its three typefaces so the site does not depend on Google Fonts at runtime.

| File | Typeface | Styles and weights |
| --- | --- | --- |
| `newsreader-latin.woff2` | Newsreader | Normal, 400–500 |
| `newsreader-italic-latin.woff2` | Newsreader | Italic, 400 |
| `space-grotesk-latin.woff2` | Space Grotesk | Normal, 400–700 |
| `jetbrains-mono-latin.woff2` | JetBrains Mono | Normal, 400–500 |

The files were retrieved from the official Google Fonts delivery service on August 4, 2026. Each typeface is distributed under the SIL Open Font License 1.1; the corresponding license text is preserved in `licenses/`.

- [Newsreader on Google Fonts](https://fonts.google.com/specimen/Newsreader)
- [Space Grotesk on Google Fonts](https://fonts.google.com/specimen/Space+Grotesk)
- [JetBrains Mono on Google Fonts](https://fonts.google.com/specimen/JetBrains+Mono)
